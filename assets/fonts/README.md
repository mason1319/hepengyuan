# 自托管网页字体

这些 woff2 是 Google Fonts 的 **latin 子集**，只覆盖拉丁字母、数字与常用标点；
中文由系统字体栈承接（PingFang SC / Songti SC / Microsoft YaHei / SimSun / Noto CJK）。

自托管的原因：本站 CSP 为 `font-src 'self'`，且国内访问 fonts.gstatic.com 不稳定。

| 文件 | 字体 | 授权 |
| --- | --- | --- |
| `literata-400-700-latin.woff2` | Literata（可变字重 400–700） | SIL Open Font License 1.1 |
| `fira-sans-400/500/700-latin.woff2` | Fira Sans | SIL Open Font License 1.1 |
| `fira-code-400-latin.woff2` | Fira Code（可变字重） | SIL Open Font License 1.1 |
| `vt323-400-latin.woff2` | VT323 | SIL Open Font License 1.1 |

OFL 允许自由使用、嵌入与再分发；保留字体名称即可。
