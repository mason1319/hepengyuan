# S1 橙黑漫画 AI 工具服务页设计规范

日期：2026-08-23  
状态：已完成结构、交互与技术确认，等待书面规范复核  
目标项目：何鹏远个人 IP 官方网站

## 1. 背景与目标

为“何鹏远 / HPY / TerraSol 明远”设计一套独立的 AI 工具服务 HTML 样板。视觉参考为橙黑高对比漫画海报：爆炸框、粗描边、网点纹理、强标题和套餐卡片；实际交付必须是标准响应式网页，而不是把一张海报当作页面。

本轮最初探索了 3 套个人 IP 方向和 3 套服务销售方向。用户最终选择只重点实现 S1“爆炸套餐台”，其余 5 套仅作为视觉探索，不进入本轮实现范围。

成功标准：页面在桌面与手机上都具有强烈漫画记忆点，同时保证服务内容清晰、可操作、合规，不虚构授权、价格、客户或承诺。

## 2. 品牌与人物身份

- 主姓名：何鹏远
- 视觉缩写：HPY
- 社交与服务署名：TerraSol 明远
- 人物基准：用户提供的国风动漫全身图；稳定特征为黑色短发、金属框眼镜、白色国风长衫和温和可信的气质。
- 辅助角色：可使用 HPY 机器人作为次要吉祥物，但不得抢占人物主视觉。

人物资产将重新处理为适合橙黑漫画页面的独立图像。人物身份特征保持稳定，湖景不作为每个版块的固定背景。优化后的网页资产必须小于 1MB，原始桌面文件不复制进仓库。

## 3. 服务与合规边界

页面只介绍以下合法服务：

- AI 工具咨询
- 安装与环境协助
- 工作流梳理与搭建建议
- 交付后的售后支持

明确不做：

- 不使用“官方充值”“官方渠道”等未经授权的表述。
- 不代售账号，不展示虚构支付流程。
- 不虚构价格、使用时长、客户、销量、到账速度或成功率。
- 不暗示与 OpenAI、Anthropic 或其产品存在官方隶属、代理或背书关系。

页面底部必须显示独立服务声明：“何鹏远 / HPY · 独立服务说明页 · 与 OpenAI、Anthropic 无隶属关系。”服务区显示：“不代售账号；实际范围、周期与费用以双方确认结果为准。”

## 5. 视觉系统

### 5.1 色彩

- 主橙：`#FF5312`
- 黑色：`#111111`
- 纸张白：`#FFFDF7`
- 奶油底：`#F7F1E7`
- 闪电黄：`#FFCE19`
- 服务蓝：`#2E7EEA`
- 服务紫：`#7239DD`

### 5.2 字体与层级

- 中文标题：系统粗黑体栈，使用 900 字重和紧凑行高。
- 英文与技术标签：等宽字体栈，仅用于少量辅助信息。
- 正文：系统无衬线字体，保持高可读性。
- 所有按钮、导航、卡片标签显式定义字号、字重和行高，不依赖浏览器默认值。

### 5.3 组件语言

- 4–5px 黑色粗描边。
- 实色偏移阴影，不使用柔和玻璃阴影。
- 网点纹理和放射爆炸线只作为背景，不压住文字。
- 爆炸对话框使用可实施的多边形轮廓；文字仍为 HTML。
- 服务卡片使用蓝、紫、橙三种偏移阴影区分等级，但不暗示价格高低。
- 图标采用统一粗线或实心漫画样式，不混用细线图标。

## 6. 交互设计

- 顶部锚点平滑滚动至对应版块。
- 点击服务卡片后高亮当前方案，并同步更新底部咨询文案。
- FAQ 使用原生、可键盘操作的折叠交互。
- “复制联系名称”将 `TerraSol 明远` 写入剪贴板，并显示成功提示；失败时显示可手动复制的文本。
- 手机端提供简洁菜单；展开时保持焦点可见，不锁死页面滚动。
- 漫画爆炸线、闪电和版块进入动效保持轻量。
- `prefers-reduced-motion: reduce` 时关闭非必要动画和顺滑滚动。
- 页面没有支付、注册、账号代售或真实网络表单提交。

## 7. 技术架构

- 新增独立目录 `samples/s1/`。
- 使用原生 `index.html`、`styles.css` 和 `script.js`。
- 不引入新的前端框架、运行时依赖、外部字体或第三方追踪脚本。
- 当前根目录主页保持不变。
- 构建脚本必须把 `samples/s1/` 和所需小型资产复制到 `dist/`。
- 核心文案、服务说明和联系名称全部为服务器直出 HTML，便于 SEO/GEO、无障碍技术和禁用 JavaScript 的用户读取。
- JavaScript 仅增强菜单、服务选择、FAQ、复制和进入动效；脚本失败时页面内容仍然完整可读。

## 8. 响应式与无障碍

- 桌面验收视口：`1440×900`。
- 参考海报验收视口：`853×1280`。
- 手机验收视口：`390×844`。
- 桌面首屏使用文本与人物双栏；手机改为标题、人物、按钮的单列顺序。
- 三档服务在桌面并列，在手机纵向排列。
- 三步流程在窄屏改为垂直时间线。
- 所有交互元素有清晰键盘焦点，颜色对比达到可读标准。
- 人物图提供描述性替代文本；纯装饰网点、闪电和爆炸线从辅助技术隐藏。
- 页面不出现水平溢出、正文裁切、按钮不可点击或移动端小于合理触控尺寸的问题。

## 9. 验收与测试

### 9.1 自动门禁

- `npm run validate`
- `npm run build`

### 9.2 浏览器验收

- 使用内置浏览器打开真实本地页面。
- 检查桌面、参考海报比例和手机视口。
- 验证导航、服务选择、FAQ、复制按钮、移动菜单和减少动态效果。
- 检查人物资产加载、裁切、背景融合和文字遮挡。
- 检查禁用 JavaScript 时核心内容仍可阅读。

### 9.3 视觉验收

- 使用生成并确认的视觉概念作为实现基准。
- 对概念图与浏览器截图执行同轮 `view_image` 对比。
- 至少检查：首屏构图、标题层级、橙黑色彩、人物融合、服务卡片、版块节奏、图标一致性、移动端折叠和动效边界。
- 完成上首屏文案差异检查，禁止引入未确认的销量、价格、客户或官方授权表述。

## 10. 非目标

- 本轮不实现其余 5 套探索样板。
- 本轮不替换或发布到 `https://hepengyuan.top/` 根主页。
- 本轮不接入支付、登录、数据库、客服系统或真实表单后端。
- 本轮不提交搜索引擎收录，也不更改现有 GEO 权威资料。
